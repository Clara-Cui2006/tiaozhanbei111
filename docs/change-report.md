## 二、各模块改动明细

### 2.1 风险预警态势盘 `/dashboard`

| 改动 | 说明 |
|---|---|
| 命名更新 | "风险预警大盘" → "风险预警态势盘" |
| KPI 卡片 | 从 4 个扩展为 5 个（新增"风险预警推送次数"） |
| 趋势图 | 单一折线图 → 5 类可切换趋势图（柱状图/折线/堆叠） |
| **AI 风险研判** | 新增「一键研判」按钮，AI 综合态势数据生成研判摘要 |

**操作流程 — AI 风险研判**:
1. 进入「风险预警态势盘」页面
2. 页面自动加载 5 大 KPI 数据和社区风险点
3. 在地图下方找到「🤖 AI 风险研判摘要」卡片
4. 点击「一键研判」按钮
5. 等待 5-10 秒，AI 生成包含以下内容的研判报告：
   - 整体态势判断
   - 重点关注区域
   - 风险预警
   - 决策建议
   - 资源调配建议
6. 可点击「重新研判」更新报告

**操作流程 — AI 案件特征分析**:
1. 进入「风险分析管理」页面
2. 点击饼图中的任意案件分类（如"侵财类犯罪"）
3. 下方三个 Tab 和案件表格会联动刷新
4. 找到「🤖 AI 案件特征智能分析」卡片
5. 点击「生成分析报告」
6. AI 基于当前选中分类的案件数据生成：
   - 总体态势
   - 重点风险
   - 检察建议素材
   - 靶向普法要点
   - 治理建议

## 三、AI 智能化架构

### 3.1 提示词管理

所有 AI 提示词集中在 `src/services/prompts.ts`：

```
prompts.ts
├── GLOBAL_CONTEXT      → 全局上下文（西城区/检察院/平台定位）
├── OUTPUT_FORMAT_RULE   → 输出格式规范（【章节标题】结构）
├── SYSTEM_PROMPTS       → 6 个模块的角色设定
└── USER_PROMPT_TEMPLATES → 6 个模块的数据注入模板
```

### 3.2 AI 调用入口

`src/services/llm.ts` — `chatWithLLM(prompt, module?)`

每次调用自动注入：
1. 对应模块的 system prompt（角色设定）
2. 全局上下文（平台背景）
3. 输出格式规范
4. 用户提示词（由模板函数 + 页面数据动态生成）

### 3.3 修改 AI 行为的方法

| 想改什么 | 改哪个文件 | 改哪里 |
|---|---|---|
| 某个模块的 AI 角色定位 | `src/services/prompts.ts` | `SYSTEM_PROMPTS.模块名` |
| 某个功能的提问方式 | `src/services/prompts.ts` | `USER_PROMPT_TEMPLATES.模块名` |
| 全局背景信息 | `src/services/prompts.ts` | `GLOBAL_CONTEXT` |
| 输出格式要求 | `src/services/prompts.ts` | `OUTPUT_FORMAT_RULE` |
| API 地址/Key/模型 | `.env` | `VITE_LLM_*` 变量 |
