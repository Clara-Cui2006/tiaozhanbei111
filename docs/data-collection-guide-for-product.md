# 数据收集指南（产品/业务人员版）

> 本文档面向产品经理和业务人员，说明平台需要收集哪些数据、每条数据包含什么信息、用 Excel 怎么填。
> 技术人员请参考 `docs/data-collection-spec.md` 获取 JSON 格式定义。

---

## 一、需要收集哪些数据？

| # | 数据名称 | 谁来提供 | 多久更新一次 | 用在哪里 |
|---|---|---|---|---|
| 1 | **案件数据** | 法院/检察院 | 每月 | 风险分析、案件详情、AI分析、地图热力图 |
| 2 | **社区信息** | 街道办/网格员 | 每季度 | 地图展示、风险研判、AI研判 |
| 3 | **检察建议** | 检察院 | 随时 | 检察建议管理、AI辅助生成 |
| 4 | **普法方案** | 检察院/司法所 | 随时 | 普法推荐、AI治理建议 |
| 5 | **效果数据** | 各街道汇总 | 每周/每月 | 效果评估统计、AI评估报告 |
| 6 | **法律条文** | 法律法规库 | 有更新时 | AI引用法律依据 |

---

## 二、每类数据要填什么？

### 表1：案件数据

> 这是最重要的数据，平台的核心功能都依赖它。

**用 Excel 收集，每行一个案件，表头如下：**

| 列名 | 必填 | 怎么填 | 示例 |
|---|---|---|---|
| 案件名称 | 是 | 简要描述案件，当事人用"某"代替 | 张某诈骗案 |
| 案号 | 是 | 法院标准案号格式 | (2026)京0102刑初123号 |
| **一级分类** | 是 | 从下表4个选项中选一个 | 侵财类犯罪 |
| **二级分类** | 是 | 从下表对应的具体罪名中选 | 诈骗罪（含电信网络诈骗） |
| 审判程序 | 是 | 一审 / 二审 / 再审 / 死刑复核 | 一审 |
| 所属街道 | 是 | 案发地所在的西城区街道名称 | 金融街街道 |
| 关键词 | 是 | 3-8个关键词，用逗号隔开 | 电信诈骗,老年群体,冒充公检法 |
| 案情简述 | 是 | 100-500字，概括案情经过 | 被告人张某通过电话冒充公安... |
| 案发日期 | 是 | 年-月-日 | 2026-03-15 |
| 案件状态 | 是 | 已判决 / 审理中 / 已撤诉 | 已判决 |
| 裁判理由 | 否 | 法院判决的主要理由 | 被告人行为构成诈骗罪... |

**案件分类对照表（必须严格按此分类）：**

| 一级分类 | 二级分类（具体罪名），选一个填 |
|---|---|
| **侵财类犯罪** | 诈骗罪（含电信网络诈骗）/ 盗窃罪 / 抢夺罪 |
| **人身伤害类犯罪** | 故意伤害罪 / 寻衅滋事罪 / 非法拘禁罪 |
| **危害公共安全类犯罪** | 危险驾驶罪 / 交通肇事罪 |
| **妨害社会管理类犯罪** | 聚众斗殴罪 / 容留他人吸毒罪 / 帮信罪 |

## 三、数据脱敏要求（非常重要！）

| # | 要求 | 说明 |
|---|---|---|
| 1 | 当事人姓名必须脱敏 | 只保留姓氏+"某"，如"张某"、"李某某" |
| 2 | 不得包含身份证号 | 如有需删除 |
| 3 | 不得包含手机号 | 如有需删除 |
| 4 | 不得包含具体地址 | 精确到街道即可，不要门牌号 |
| 5 | 涉及未成年人的额外脱敏 | 年龄写"未成年"，不写具体岁数 |

## 四、数据交付方式

### 推荐方式：Excel 文件

- 每类数据一个 Sheet（或一个独立的 Excel 文件）
- 表头严格按照上面的列名
- 文件命名规范：`案件数据_2026年4月.xlsx`、`社区信息_2026Q2.xlsx`
- 编码：保存为 `.xlsx` 格式（不要用 `.xls`）

### 交付频率建议

| 数据类型 | 建议频率 | 说明 |
|---|---|---|
| 案件数据 | 每月1次 | 每月初交上月新增案件 |
| 社区信息 | 每季度1次 | 或有重大变化时更新 |
| 检察建议 | 随时 | 每发一条就录入 |
| 普法方案 | 随时 | 每出一个就录入 |
| 效果数据 | 每周/每月 | 和评估周期对齐 |
| 法律条文 | 有更新时 | 新法出台或修订时 |

## 五、常见问题

**Q: 案件分类不在上面4个类别里怎么办？**
A: 先按最接近的分类填，同时在"关键词"里注明实际罪名。后续我们可以扩展分类。

**Q: 有些字段不确定怎么填？**
A: 必填字段尽量填完整，选填字段空着没关系。有比没有好，不完美比不填强。

**Q: 历史数据要收集多久的？**
A: 优先收集近3年的数据。如果工作量太大，至少收集近1年的。

**Q: 数据量大概需要多少？**
A: 案件数据建议至少 100 条以上，效果才比较好。越多越好，AI 分析会越准确。

**Q: 收集好的数据发给谁？**
A: 发给开发团队，我们会转换成系统需要的格式导入平台。
