# 西城区社区法治风险预警平台 — 本地运行指南

> 本文档面向不熟悉编程的同学，按步骤操作即可在自己电脑上运行平台。

---

## 第一步：安装 Node.js（只需装一次）

平台需要 Node.js 环境才能运行。如果你的电脑还没装过，按下面操作：

### Windows 用户

1. 打开 https://nodejs.org/zh-cn
2. 点击页面上绿色的 **"下载 Node.js (LTS)"** 按钮
3. 双击下载的安装包，**一路点「下一步」**，全部默认即可
4. 安装完成后，打开「命令提示符」（按 Win+R，输入 `cmd`，回车）
5. 输入 `node -v`，如果显示类似 `v20.x.x` 的版本号，说明安装成功

### Mac 用户

1. 打开 https://nodejs.org/zh-cn
2. 点击绿色的 **"下载 Node.js (LTS)"** 按钮
3. 双击下载的 `.pkg` 文件，按提示安装
4. 打开「终端」（在启动台搜索"终端"）
5. 输入 `node -v`，显示版本号即安装成功

---

## 第二步：解压文件

把收到的压缩包解压到任意位置，比如桌面。解压后会看到一个文件夹（如 `Tiaozhanbei`）。

---

## 第三步：安装依赖（只需装一次）

### Windows

1. 打开文件夹 `Tiaozhanbei`
2. 在文件夹空白处，**按住 Shift 键 + 右键**，选择「在此处打开 PowerShell」或「在终端中打开」
3. 输入以下命令，然后回车：

```
npm install
```

4. 等待安装完成（可能需要 1-3 分钟，期间会显示进度条）
5. 看到类似 `added xxx packages` 的提示就算成功了

### Mac

1. 打开「终端」
2. 输入 `cd `（注意 cd 后面有个空格），然后**把文件夹从 Finder 拖到终端窗口**，回车
3. 输入以下命令，然后回车：

```
npm install
```

4. 等待安装完成

> 如果提示权限错误，在命令前加 `sudo`：`sudo npm install`

---

## 第四步：启动平台

在同一个命令窗口中，输入：

```
npm run dev
```

看到类似下面的输出就算启动成功了：

```
  VITE v8.x.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
```

**打开浏览器**（推荐 Chrome），在地址栏输入：

```
http://localhost:5173/
```

回车，就能看到平台了！

| 操作 | 怎么做 |
|---|---|
| **启动平台** | 打开终端，进入文件夹，输入 `npm run dev` |

## 常见问题

### Q: `npm` 不是内部命令 / command not found

Node.js 没有安装成功。请重新执行第一步。

### Q: 安装依赖时报错很多红色文字

尝试删除 `node_modules` 文件夹，然后重新运行 `npm install`：

```
# Windows
rmdir /s /q node_modules
npm install

# Mac
rm -rf node_modules
npm install
```

### Q: 地图显示空白

需要联网才能加载高德地图。请确保电脑能正常上网。

### Q: AI 功能（如一键研判）没有反应

需要联网才能调用智谱大模型 API。请确保电脑能正常上网。

### Q: 端口被占用（提示 5173 already in use）

关掉之前没关的终端窗口，或者改用其他端口：

```
npm run dev -- --port 3000
```

然后浏览器打开 `http://localhost:3000/`
