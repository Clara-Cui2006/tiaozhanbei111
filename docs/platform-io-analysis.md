# 平台输入/输出全景图

## 一、数据从哪来（输入源）

| 输入类型 | 当前状态 | 说明 |
|---|---|---|
| **案件数据** | ⚠️ 硬编码 Mock | 所有案件、社区风险点、趋势数据都写死在 `src/api/platform.ts` 里 |
| **用户手动输入** | ✅ 已有 | 检察建议新建/编辑表单、系统设置表单 |
| **用户搜索/筛选** | ✅ 已有 | 风险分析搜索框、检察建议多条件筛选 |
| **AI 大模型（智谱 GLM-4.5）** | ✅ 部分接入 | 普法方案详情页调用智谱生成治理建议；检察建议、风险分析、态势盘、案件详情、效果评估待接入 |
| **实时推送** | ⚠️ 预留 | WebSocket 接口已搭好，但无真实数据源 |

## 二、用户在哪里输入

| 页面 | 输入方式 | 输入什么 |
|---|---|---|
| **检察建议** | 表单 | 建议标题、类型（四大检察）、对象、日期、正文 |
| **检察建议** | 筛选栏 | 类型、状态、对象、日期范围、关键词 |
| **风险分析** | 搜索框 | 案号、案由、关键词 |
| **风险分析** | 饼图点击 | 选择案件分类 → 联动刷新子图表和表格 |
| **普法方案详情** | AI 按钮 + 编辑框 | 点击生成 → AI 输出 → 可手动修改 |
| **系统设置** | 表单 | 平台名称、预警阈值、推送开关 |
| **态势盘** | RadioGroup | 切换趋势图维度（5类） |
| **效果评估** | RadioGroup | 切换统计时段（本周/本月/全年） |
| **地图** | 点击/切换 | 点击社区点位查看详情；切换 10 种分类维度 |

## 三、平台输出什么（展示）

| 页面 | 输出内容 |
|---|---|
| **主页** | 风险地图 + 普法方案推荐列表 + 官方动态 |
| **态势盘** | 5个KPI数字 + 风险地图（10种分类） + 5类趋势图 |
| **风险分析** | 案件类型饼图 + 主体画像（年龄/性别/户籍） + 时间趋势 + 词云 + 案件明细表 |
| **案件详情** | 案件描述列表（名称/案号/类别/程序/关键词/裁判理由） |
| **检察建议** | 分类饼图 + 趋势线 + 建议列表（CRUD） + 实时动态流 |
| **普法方案** | 统计数字 + 方案卡片（标签/资源/数据摘要） + AI治理建议 |
| **预警推送** | 推送任务表 + 统计卡片 + WebSocket状态 |
| **效果评估** | 6个KPI + 6个进度条 + 双轴趋势 + 雷达图 + 社区对比柱状图 + 环形图 |
| **系统设置** | 配置表单 |
| **往期窗口** | 历史文章列表（4个分类Tab） |

## 四、AI 接入点（智谱 GLM-4.5）

| # | 模块 | AI 功能 | 输入 | 输出 | 状态 |
|---|---|---|---|---|---|
| 1 | **普法方案详情** | AI 生成治理建议 | 方案的人群/场景/罪名/画像/法律依据 | 600-800字治理建议 | ✅ 已接入 |
| 2 | **检察建议** | AI 辅助生成检察建议 | 建议类型+社区情况+案件数据 | 结构化建议正文 | 🔧 待接入 |
| 3 | **风险分析** | 案件特征智能分析 | 当前分类的案件数据汇总 | 分析报告+普法要点 | 🔧 待接入 |
| 4 | **态势盘** | AI 风险研判摘要 | 5大KPI数据+社区风险点 | 研判摘要文本 | 🔧 待接入 |
| 5 | **案件详情** | AI 案情分析 | 案件全部字段 | 案情分析+处置建议 | 🔧 待接入 |
| 6 | **效果评估** | AI 生成评估报告 | KPI数据+社区统计+趋势 | 评估报告+改进建议 | 🔧 待接入 |

## 六、环境变量

| 变量 | 值 | 用途 |
|---|---|---|
| `VITE_USE_MOCK` | 默认 true | 是否使用 Mock 数据 |
| `VITE_API_BASE_URL` | `/api` | 后端 API 地址 |
| `VITE_WS_URL` | 未设置 | WebSocket 地址 |
| `VITE_LLM_BASE_URL` | `https://open.bigmodel.cn/api/paas/v4` | 智谱大模型 API |
| `VITE_LLM_API_KEY` | `7d2780a...` | 智谱 API Key |
| `VITE_LLM_MODEL` | `glm-4.5` | 使用的模型 |
