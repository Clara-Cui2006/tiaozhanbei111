# 首页账号框滚动行为设计

## 目标

首页账号框继续显示在主视觉区右上角，并随首页内容向上滚出视口。滚动经过吸顶栏时，吸顶栏覆盖账号框，避免账号框出现在“红墙智检”顶栏上方。浅色和深色模式保持一致。

## 方案

- 在布局根节点内增加首页账号层，层级低于吸顶栏。
- 使用 Vue `Teleport` 将现有账号框在首页放入账号层，在其他页面放入顶栏预留位。
- 首页账号框使用文档内绝对定位，保留现有右上角视觉位置。
- 移动端继续隐藏机构长名称，并调整账号框的顶部和右侧间距。

## 验证

- 自动检查首页账号框未使用视口固定定位，并确认首页账号层低于吸顶栏。
- 在浅色、深色模式分别滚动页面，确认账号框随内容上移并被吸顶栏遮挡。
- 运行 Vue 类型检查和生产构建。
