# 风险分析大盘正式 API 与预览数据设计

## 数据口径

- `cases.category`：刑法分则章名，用于大盘外圈。
- `cases.crime` / `cases.legal_cause`：具体罪名或案由。
- `cases.governance_themes`：六个社会治理一级分类，可多选，用于大盘内圈。
- 当事人姓名、年龄、性别、职业、特殊身份作为可选导入字段，用于涉案主体画像。
- 后续院内接口或文件只要写入同一数据库字段，即可复用相同查询接口。

## 正式接口

- `GET /risk-analysis/case-categories`：按治理主题统计内圈，并按刑法分则章名统计外圈。
- `GET /risk-analysis/case-subjects?category=`：返回所选治理分类的涉案主体。
- `GET /risk-analysis/case-time-trends?category=`：按月统计所选治理分类案件。
- `GET /risk-analysis/case-feature-words?category=`：从关键词、重点人群和重点行业提取特征词。
- `GET /risk-analysis/case-details?category=`：当参数为六个治理分类之一时，按治理主题筛选案件；其他值保留案件类别精确筛选。

所有接口沿用现有用户权限范围，不绕过案件读取权限。

## 预览数据

- 新增18条匿名样例案件，每个治理分类3条。
- 覆盖当前外圈使用的刑法分则章名与多个街道、月份、主体画像字段。
- 样例数据写入独立导入批次，案件编号使用 `PREVIEW-RISK-` 前缀。
- 种子脚本重复执行不重复插入；`--clear` 仅清除该批次样例数据。
- 样例数据不在应用启动时自动写入，避免进入院内部署数据库。

## 验收

- 非 Mock 模式下五个风险分析接口返回数据库数据。
- 六个内圈分类均有数据，外圈仅出现批准的刑法分则章名。
- 分类切换能够更新主体、时间、词云和案件列表。
- 导入解析器接受新增主体字段，旧模板不填写时仍可导入。
- 样例数据能够插入和独立清除。
